# GhostFlow Digital Experience

Crie o layout completo, moderno e responsivo do site institucional da GhostFlow, uma empresa de tecnologia especializada em desenvolvimento de software e soluções digitais.

Identidade da marca

A marca se chama GhostFlow.

A identidade visual possui:

Logo de um pequeno fantasma minimalista desenhado em linhas

Cor principal: azul-marinho muito escuro

Cor de destaque: turquesa/ciano

Fundo branco/off-white

Estética minimalista, tecnológica, moderna e amigável

O conceito visual da marca deve transmitir:

tecnologia + fluidez + automação + inovação + simplicidade

O nome "GhostFlow" deve inspirar elementos visuais relacionados a fluxo, movimento, conexões e processos digitais, mas de forma sofisticada e sutil.

Evite uma estética infantil ou temática de Halloween. O fantasma é apenas um elemento simpático e memorável da identidade da empresa.

EXPERIÊNCIA MOBILE

O site deve ser pensado primeiro para mobile e depois adaptado para desktop.

No mobile:

títulos devem quebrar de forma elegante

botões principais podem ocupar quase toda a largura

cards ficam em uma coluna

menu vira hambúrguer

evitar textos excessivamente largos

manter espaçamento confortável

CTA do WhatsApp pode ficar flutuante no canto inferior direito

nenhuma seção pode gerar scroll horizontal

respeitar safe areas de iOS e Android

MICROINTERAÇÕES

Adicionar animações elegantes e discretas:

elementos aparecendo suavemente durante o scroll

cards subindo alguns pixels no hover

botões com pequenas transições

linhas de fluxo animadas lentamente

pontos percorrendo caminhos no background

header com efeito de blur durante o scroll

As animações devem reforçar o conceito de Flow, sem deixar o site pesado.

IMPORTANTE

O resultado deve parecer uma empresa de tecnologia real e estabelecida, não um template genérico de landing page.

Priorizar:

identidade própria + clareza + conversão + tecnologia + confiança

A personalidade visual da GhostFlow deve ser percebida principalmente através da combinação:

azul-marinho + turquesa + branco + fantasma minimalista + elementos de fluxo
